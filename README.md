# Finance Bot

Telegram-бот для записи личных расходов. В текущем каркасе есть:

- регистрация и обновление профиля Telegram-пользователя;
- главное меню с inline-кнопками;
- пошаговое добавление расхода: сумма → категория → комментарий;
- отмена добавления кнопкой или командой `/cancel`;
- просмотр 10 последних расходов;
- безопасное удаление последнего расхода с подтверждением;
- PostgreSQL-модели и Alembic-миграции для пользователей и расходов.

## Модель расхода

Расход связан с пользователем и содержит сумму `NUMERIC(12, 2)`, валюту, категорию,
необязательный комментарий, дату расхода и дату создания записи.

## Запуск

1. Скопируйте `.env.example` в `.env` и укажите токен Telegram, публичный HTTPS URL
   вебхука, секрет вебхука и параметры БД.
2. Запустите сервисы:

   ```bash
   docker compose up --build
   ```

Контейнер `migrate` автоматически выполняет `alembic upgrade head` перед запуском
приложения. Для ручного применения миграций используйте:

```bash
alembic upgrade head
```

Команды бота:

- `/start` — регистрация и открытие главного меню;
- `/menu` — открыть главное меню;
- `/help` — показать инструкцию по использованию бота;
- `/stats` — показать расходы за текущий месяц по категориям;
- `/cancel` — отменить добавление расхода.
